# VeriVox Android Prototype

This is a native Android WebView wrapper around the VeriVox UI prototype.

## Build

### Option A — Android Studio (recommended, easiest)
Open this folder in Android Studio and let Gradle sync.
Then choose:
Build -> Build Bundle(s) / APK(s) -> Build APK(s)

The generated debug APK will be under:
app/build/outputs/apk/debug/app-debug.apk

### Option B — GitHub Actions (no install needed)
This project includes `.github/workflows/build-apk.yml`.
1. Push this folder to a new GitHub repository.
2. Go to the repo's "Actions" tab and run the "Build VeriVox APK" workflow (or just push to `main`).
3. When it finishes, open the run and download the `VeriVox-debug-apk` artifact — that's your installable APK.

## App icon
Launcher icons (legacy + adaptive, all densities) have been generated from the VeriVox logo and added under `app/src/main/res/mipmap-*`.

## Current scope
- VeriVox call-log UI
- AI / Real / Upload simulation
- Incoming-call interaction
- Ringing sound generated by the browser Web Audio API
- Analysis animation
- AI/Real result screen
- Dark/light mode
- Upload-audio file picker

This is currently a demo/prototype app. The actual ML detector is not connected yet.
